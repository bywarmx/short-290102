Documentación de la API

Crea enlaces acortados, personaliza alias, define tiempos de expiración y consulta estadísticas de visitas desde tus terminales o aplicaciones.

Base URL https://short.290102.xyz
Uso rápido desde consola / Terminal (Texto Plano)

Si agregas format=text (o envías la cabecera Accept: text/plain), la API devuelve únicamente la URL acortada, lista para usar en tuberías (pipes) de bash:

curl -s "https://short.290102.xyz/api/shorten?url=https://ejemplo.com&format=text"

Ejemplos de Integración

Selecciona tu entorno o lenguaje para ver el código de ejemplo listo para copiar.

POST /api/shorten 
curl -s -X POST https://short.290102.xyz/api/shorten \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://290102.xyz/descargas",
    "alias": "descargas",
    "ttl": 86400
  }'
Respuesta JSON (HTTP 200): 
{
  "ok": true,
  "shortUrl": "https://short.290102.xyz/descargas",
  "slug": "descargas",
  "targetUrl": "https://290102.xyz/descargas",
  "expiresAt": 1792559582,
  "createdAt": 1792473182
}
GET /api/shorten 
# 1. Devuelve directamente la URL corta en texto plano (sin JSON)
curl -s "https://short.290102.xyz/api/shorten?url=https://290102.xyz&alias=inicio&format=text"

# 2. O en formato JSON estándar:
curl -s "https://short.290102.xyz/api/shorten?url=https://290102.xyz"
JavaScript / Fetch (Browser & Node.js) 
const res = await fetch("https://short.290102.xyz/api/shorten", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    url: "https://ejemplo.com/recurso",
    alias: "mialias",   // Opcional
    ttl: 86400          // Opcional en segundos (ej. 24h)
  })
});

const data = await res.json();
if (data.ok) {
  console.log("Enlace acortado:", data.shortUrl);
} else {
  console.error("Error:", data.message);
}
Python 3 (requests) 
import requests

res = requests.post(
    "https://short.290102.xyz/api/shorten",
    json={
        "url": "https://ejemplo.com/recurso",
        "alias": "enlace-py",  # opcional
        "ttl": 86400           # segundos de expiración
    }
)
data = res.json()
print("URL acortada:", data["shortUrl"])
GET /api/stats/:slug 
curl -s https://short.290102.xyz/api/stats/descargas
Respuesta: 
{
  "ok": true,
  "link": {
    "slug": "descargas",
    "target_url": "https://290102.xyz/descargas",
    "created_at": 1792473182,
    "expires_at": 1792559582,
    "clicks": 42
  },
  "isExpired": false
}

Parámetros Aceptados (/api/shorten)

La API acepta tanto JSON en POST, formularios codificados, como parámetros en URL (GET).

Parámetro Tipo Requerido Descripción
url string Sí La URL de destino completa (debe iniciar con http:// o https://).
alias / customSlug string No Alias deseado (2 a 32 caracteres alfanuméricos). Si se omite, se genera uno corto Base62.
ttl / ttlSeconds number No Tiempo de vida en segundos. Por defecto 1296000 (15 días). Mínimo 300 (5m), máximo 31536000 (1 año).
format string No Si se pasa format=text, la API responde únicamente la URL en texto plano (ideal para scripts de terminal).

Códigos de Estado y Respuestas de Error

Código Error Causa
200 OK - Enlace acortado con éxito o consulta de estadísticas correcta.
302 Found - Redirección al destino con cabeceras de caché Edge.
400 Bad Request invalid_url La URL no inicia con http:// o https://, o intenta acortar el propio dominio.
404 Not Found not_found El alias no existe o ha expirado.
409 Conflict slug_taken El alias personalizado ya se encuentra en uso activo por otro enlace.
